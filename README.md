# 回転体をつくろう（中学1年 数学「空間図形」）

平面図形と回転の軸をかくと、図形が軸のまわりを1周して回転体ができるようすを3Dで確かめられるWeb教材です。
iPad（Safari）を中心に、パソコンのブラウザでも使えます。指・Apple Pencil・マウスのどれでも操作できます。

---

## 生徒のみなさんへ：使い方

画面の左に、手順が①〜④の順にならんでいます。今やると良い手順に色が付きます。
③と④は、何度でもくり返して試しましょう。

1. **① 図形をえらぶ**
   「三角形」「四角形」「円」「半円」のどれかを押すと、方眼に図形が置かれます。
   自分で考えた形を使いたいときは、「フリーハンドでかく」を押して、指やペンでかきます（下の「フリーハンドでかく」を見てください）。
2. **② 軸をひく**
   「軸をひく」を押して、方眼の上を指でなぞります（2か所をタップしてもひけます）。赤い点線が「回転の軸」です。
3. **③ 形や位置を変えてみる**
   - **点を動かす**：●を指で動かすと、形や大きさが変わります。図形の内側を動かすと、図形全体が動きます。
   - **図形を回す・裏返す**：図形をタップすると、まわりに点線の枠と2つのボタンが出ます。
     - 上の丸いつまみをぐるっと動かすと、図形が回ります（15°ずつ）。
     - 横のボタンを押すと、図形が裏返ります。裏返し方は、図形と軸の位置で変わります。
       - 軸がないとき・図形が軸から離れているとき → その場で左右に裏返ります（点線の枠の位置は変わりません）。
       - 図形が軸に接しているとき（緑の●が出ているとき）・軸が図形の中を通るとき → 軸を対称の軸にして、軸の反対側に裏返ります。ボタンのまん中の線が赤い点線になります。
       - 円は、その場で裏返しても同じ形なので、軸に接している・軸が中を通るときだけボタンが出ます。
     - 何もない所をタップすると、枠が消えます。
   - **軸を動かす**：◆（ひし形）を動かすと、軸の位置が変わります。
   - **軸にぴったり合わせる**：●を軸に近づけると、軸に吸い付いて、**緑の●にチェック印**が付きます。
     - 吸い付いたまま動かすと、軸の上をすべります。軸から大きく離すと外れます。
     - 円の中心の●を軸に近づけると、中心が軸の上に乗ります。
     - 円の大きさを決める●を軸に近づけると、軸の上をすべって円の大きさが変わります。円が軸にぴったり接する位置にも吸い付きます。
4. **④ 回転体をつくる**
   「回転体をつくる」を押すと、右側で図形が軸のまわりを1周して、回転体ができます。
   できたら、③にもどって形や軸の位置を変えて、もう一度つくってみましょう。

**フリーハンドでかく**

1. 「フリーハンドでかく」を押します（ボタンの色が変わります）。
2. 方眼の上を、指やペンで、図形のまわりをぐるっと1筆でかきます。かき始めの所に点線の○が出ます。
3. 指を離すと、線が閉じた図形になります。指のふるえによる線のがたがたは、なめらかに整えられます（とがった角は角のまま残ります）。

線の閉じ方は、かき終わりの場所で決まります。

- かき始めの○にもどって離す → そのまま閉じます（○は、指先が入ると濃くなります）。
- かき始めの所を少し通り越す → はみ出した線を切って閉じます。
- 軸をひいてから、軸の近くから軸の近くまでかく → 線の両はしを軸に乗せて、軸と線で囲みます（両はしに緑の印が出ます）。
- 途中でやめる → かき終わりからかき始めまで、まっすぐな線で閉じます。その線はしばらく点線で目立たせます。ちがうときは「元に戻す」でかき直しましょう。

こんなときは、かき直しになります。

- 線が交わっている（8の字など）→「線が交わらないようにかこう。○の所で交わっています。」（交わった所に点線の○が出て、かいた線がうすく残ります）
- 小さすぎる・細すぎる → 「もう少し大きくかこう」

かいた図形は、ほかの図形と同じように、動かす・回す・裏返す・軸に吸い付ける（軸にぴったり接する位置に吸い付きます）ことができます。
点を1つずつ動かすことはできないので、形を変えたいときは「フリーハンドでかき直す」を押して、かき直しましょう。
「フリーハンドでかく」「フリーハンドでかき直す」を押すと、今ある図形（三角形などもふくむ）はすぐに消えます。軸は残ります。消えた図形は「元に戻す」で戻せます。
かいている途中で2本目の指が触れると、かいていた線は消えて、2本指の拡大・縮小に変わります。

**こまったとき**

- 画面の右上の ⓘ を押すと、この使い方を教材の中で読めます（「生徒向け」「先生向け」をタブで切りかえます）。
- 「元に戻す」を押すと、図形や軸の操作を1つずつ戻せます。戻しすぎたときは、となりの「進む」で、戻した操作をもう一度やり直せます。
- 「図形だけ消す」を押すと、軸は残したまま、図形だけを消せます（「元に戻す」で戻せます）。
- 図形が画面からはみ出したら、2本の指で広げたりせばめたりすると、大きく・小さく見られます。2本の指をすべらせると、方眼が動きます。
- 「全体を表示」を押すと、図形と軸がぜんぶ見える大きさにもどります。
- 「全部消す」を押すと、図形も軸も消えて、最初からやり直せます（「元に戻す」で戻すこともできます）。

**軸が図形の中を通るとき**

- 軸が図形の中を通っていても、回転体をつくれます。
- 案内の欄に出る「折り返しを見る」をオンにすると、軸の反対側の部分を軸で折り返した形が**青の斜線**で表示されます。
- 濃い青の線でかこまれた形が、回ってできる立体の形になります。

**右側の立体の見かた**

- 1本指でなぞる → 立体が回る
- 2本指で広げる・せばめる → 大きく・小さく見える（マウスのときはホイール）
- 「軸のまわりに回した角度」のつまみ → 好きな角度（たとえば90°）で止めて、そこまで回したようすを見る
- 「もう一度」 → 回転のようすをもう一度見る
- 「半透明」（スイッチ） → 立体がすけて、中の軸ともとの図形が見える
- 「はじめの向きにリセット」 → 見る向きをもとにもどす

**ためしてみよう**

- 長方形の1辺の上に軸をひくと → 円柱
- 直角三角形の、直角をはさむ辺の上に軸をひくと → 円錐
- 円を軸からはなすと → ドーナツの形
- 円を軸にぴったり接するようにすると → まん中の穴が点になったドーナツの形
- 長方形を軸からはなすと → まん中が空洞の円柱
- 円の中心を軸の上に乗せると → 球
- 半円の直径を軸に重ねると → 球
- 長方形のまん中に軸を通すと → 円柱（半径は幅の半分）。軸を左右 1:2 の位置にずらすと、どんな円柱になるかな？
- 三角形を回したり裏返したりしてから軸に合わせると、どんな立体になるかな？
- 軸に接している図形を裏返して（軸の反対側に移して）から「回転体をつくる」と、立体はどうなるかな？
- 軸をひいてから、軸から軸まで半円のような弧をフリーハンドでかくと → 球に近い形。弧をゆがめると、どんな形になるかな？
- つぼ・こま・びんなど、身のまわりの回転体の半分の形をフリーハンドでかいて、回してみよう。

### 教材の開き方

- **インターネットで公開して使う（おすすめ）**：GitHub Pages で公開すると、生徒は URL を開くだけで使えます（手順は下）。

学校のネットワークで外部サイト（CDN）が遮断されていても動きます。

1. 教材のファイルが `main` ブランチに入っていることを確認します。

### 授業での使い方の例

- 「長方形のどの辺を軸にすると、どんな円柱ができるか」を予想させてから確かめる。
- 同じ直角三角形でも、軸にする辺を変えると円錐の形が変わることを比べる。
- 軸を図形から少しずつはなしていき、円柱 → 空洞のある円柱、円 → ドーナツ形 と変わるようすを観察する。
- 「半透明」にして、立体の中にもとの平面図形と軸があることを確認する。
- 「軸のまわりに回した角度」のつまみで 90°・180° などで止め、図形が通った跡が立体になっていくようすを説明する。
- 半円の直径を軸にして球ができることを確かめ、円の中心を軸に乗せた場合と比べる（どちらも同じ球になる理由を考える）。
- 長方形の中に軸を通し、軸の位置を動かしながら円柱の太さがどう変わるかを予想させる。「折り返しを見る」で、広い側だけが立体の形を決めることを確かめる。
- 身のまわりの回転体（つぼ・こま・電球など）を見せて、「どんな平面図形を回せばできるか」をフリーハンドでかかせ、回して確かめる。

### 作図のきまり

- 図形は一度に1つです。別の図形のボタンを押すと置きかわります（「元に戻す」で前の図形に戻せます）。
- 「元に戻す」で戻せるのは、図形と軸の操作です（図形を置く・動かす・形を変える・回す・裏返す、軸をひく・動かす、フリーハンドでかく、図形だけ消す・全部消す）。拡大・縮小や方眼の移動は戻しません。
- 「進む」は、「元に戻す」で戻した操作をもう一度やり直します。元に戻したあとで新しい操作をすると、それより先には「進め」なくなります（ボタンが薄くなります）。
- 「フリーハンドでかく（かき直す）」を押すと、その時点で今の図形を消します（前の図形の上に重ねてかくと、かき足していると誤解しやすいため）。図形ができたあとに「元に戻す」を押すと、1回目で図形のない状態に、2回目で前の図形に戻ります。
- 図形を回すときは、図形の中心（三角形・四角形は重心、半円は直径の中点）のまわりに15°ずつ回ります。回した図形の頂点は方眼の交点からずれますが、その頂点を動かすまでは方眼に合わせ直しません。円は回しても同じなので、回すつまみは出ません。
- 図形を裏返すときは、図形と軸の位置で裏返し方が変わります（三角形・四角形・円・半円・フリーハンドのどれも同じ決まり）。
  - 軸がない、または図形が軸から離れているとき：図形を囲む点線の枠の中央を通る縦の線で、左右に裏返します。点線の枠、回すつまみ、裏返すボタンの位置は変わりません。軸が斜めでも、画面の左右に裏返します。
  - 図形が軸に接しているとき（頂点が軸の上にある、辺が軸に重なる、円やフリーハンドの線が軸に接するなど。緑の●が出ている状態）：軸を対称の軸にして裏返します。図形は軸の反対側に移り、軸に触れている点は動きません。案内の欄に「軸を対称の軸にして裏返しました。」と出ます。
  - 軸が図形の中を通るとき：軸を対称の軸にして裏返します。裏返した図形は、「折り返しを見る」で表示される折り返しの形と重なります。
  - 円は、軸に接している・軸が中を通るときだけ裏返すボタンが出ます。
  - 軸で裏返しても、できる回転体は同じです（テストで体積が変わらないことを確かめています）。
- 頂点・円の中心・軸の点は方眼の交点に、円の半径は 0.5 ます刻みに吸いつきます。このため、辺の上にぴったり軸を引けます。
- 軸を引いたあとは、図形の点が軸にも吸い付きます（画面上でおよそ20ピクセル以内に近づけたとき）。
  - 頂点：軸の上に乗り、軸の上をすべります。軸の上の方眼の交点の近くでは、その交点に乗ります。図形全体を動かしたときも、軸に近づいた頂点が軸に乗ります。
  - 円：大きさを決める●を軸に近づけると軸の上に乗り、軸の上をすべって半径が変わります（円が軸と2点で交わる）。円が軸に接する位置（半径 ＝ 中心から軸までの距離）と、軸の上の方眼の交点にも吸い付きます。
    中心の●は、軸の上に乗る位置と、円が軸に接する位置に吸い付きます（両方が近いときは近い方）。接したまま中心を動かすと、軸に沿ってすべります。
  - 半円：直径の両はしの●は、三角形の頂点と同じように吸い付きます。
  - 軸にぴったり合っている点は緑色で表示され、案内の欄にも「緑の●は、軸にぴったり合っています」と出ます。
  - 斜めの軸でも同じように吸い付きます。斜めの軸の場合、吸い付いた頂点は方眼の交点からずれることがあります（それで正しい位置です）。
- 四角形は、辺が交差する形やつぶれた形にはなりません（そうなる動かし方は受け付けません）。半円の直径は1ます以上です。

### フリーハンドの図形のきまり

- 指を離したあと、次の順に処理します（距離はすべて画面上のピクセルなので、拡大・縮小しても同じ感覚でかけます）。
  1. **閉じ方を決める**（上から順に調べる）
     - かき始めの部分（線の長さの最初の3割）とかき終わりの部分（最後の3割）が交わっている → 交わった所で切って閉じます。2か所以上で交わっているときは、閉じた形の面積がいちばん大きくなる所で切ります。
     - かき終わりが、かき始めから 36 ピクセル以内 → そのまま閉じます。
     - 軸がひいてあり、両はしがどちらも軸から 20 ピクセル以内 → 両はしを軸の上に乗せて、軸に沿った線で閉じます。
     - どれでもない → まっすぐな線で閉じて、その線を約4秒、点線で目立たせます。
     - 「始点の近くで止める」より「交わり」を先に調べるのは、少し通り越して止めたときに、小さな8の字ができてかき直しになるのを防ぐためです。
  2. **小さな戻りを取り除く**：少し戻ってまた進んだ所（Apple Pencil を離すときの「はね」など）や、面積がとても小さな輪（約10ピクセル四方以下）は取り除きます（戻りは閉じ方を決める前に、輪は閉じたあとに取り除きます）。
  3. **整える**：約3ピクセルおきに点を並べ直し、とがった角（向きが約55°以上変わる所）を見つけます。角と角の間だけ、指のふるえをならします（形が内側に縮まないならし方を使っています）。角・軸の上の点・直線で閉じた所の両はしは動かしません。
  4. **点を間引く**：形のずれが約0.5ピクセル以内になるように、点を間引きます（多くても300個）。なめらかな円に近い形で50〜100個ほどになります。
  5. **かき直しの判定**：線が交わっている、または小さすぎる・細すぎるときは、図形にしません。線が交わっているときは、交わった所を約4秒表示します。
- 図形を回すときは面積の重心のまわりに15°ずつ回ります。裏返し方は、ほかの図形と同じ決まりです。
- 図形全体を動かして軸に近づけると、軸にいちばん近い所が 20 ピクセル以内のとき、軸にぴったり接する位置に吸い付きます（緑の印が出ます）。
- これらの値（36 ピクセル・20 ピクセル・ならす回数・点の数の上限など）は、`js/freehand.js` の先頭の `Freehand.CONFIG` にまとめてあり、そこを書きかえると調整できます。

### 回転体の正しさについて

軸が図形の中を通るときの回転体は、「軸の片側の部分」と「反対側の部分を軸で折り返したもの」を重ねた形（重なった部分は1つにまとめる）を1周させたものになります。
この教材では、どの図形でも、この「折り返して重ねた形」の輪郭を求め、それを軸のまわりに1周させてできる面で立体をつくっています（軸の上にある輪郭は面にしません）。
軸をまたがない図形では、折り返す部分がないので、図形の輪郭をそのまま回すことになります。
このため、軸が辺に重なる場合（円柱・円錐）、軸が図形から離れている場合（空洞の円柱・ドーナツ形）、軸が図形の中を通る場合（球など）のどれも、数学的に正しい形になります。
円と半円は、細かい多角形（円は128角形）として計算しています。体積の誤差は 0.1% 程度です。
フリーハンドの図形は、整えたあとの点を結んだ多角形として計算します。3Dでは、角の所は角として、それ以外はなめらかな面として表示します。

右側のアニメーションでは、もとの図形全体が軸のまわりを回るようすを見せ、通った跡（完成した立体）は上の方法でつくった形になります。

`tests/geometry.test.js` で、できた立体の体積が教科書の公式（円柱 πr²h、円錐 πr²h/3、ドーナツ形 2π²Rr² など）と合うことを確かめています。
軸に吸い付けてつくった形（軸に接する円、頂点や辺が斜めの軸の上にある三角形など）の体積も確かめています。
軸が図形の中を通る場合は、球（4/3πr³）・円柱の公式に加えて、テストの中に別に書いた計算（軸に沿って細かく切った断面を式で直接求め、折り返して重ね、足し合わせる）の体積とも比べています。縦・横・斜めの軸で確かめています。
吸い付きの動き（吸い付く・すべる・外れる）は `tests/snap.test.js`、図形を回す・裏返す計算は `tests/transform.test.js` で確かめています（その場で裏返しても枠が動かないこと、軸で裏返すと軸に触れている点が動かず、折り返しの形と重なり、体積が変わらないこと。縦・横・斜めの軸）。
フリーハンドの線の閉じ方・整え方は `tests/freehand.test.js` で確かめています。指のふるえに見立てたぶれを加えた線で、4つの閉じ方とかき直しになる場合、整えても円が縮みすぎないこと、角が残ること、ドーナツ形・球・円柱・空洞の円柱の体積が公式と 1% 以内で合うこと（縦・横・斜めの軸）を確かめています。
Node.js が入っているパソコンでは `node tests/geometry.test.js`、`node tests/snap.test.js`、`node tests/transform.test.js`、`node tests/freehand.test.js` で実行できます（授業で使うだけなら不要です）。

### まだできないこと

- 図形を2つ以上置くこと
- フリーハンドの図形の点を1つずつ動かすこと、かいた線を三角形・円などの正しい形に自動で直すこと
- 作った図形の保存・印刷

### 今後の拡張のためのメモ（開発する人向け）

- 前提・デザインの方針・テストのしかたは `CLAUDE.md` にまとめてあります。
- **README を直したら、`node tools/readme-to-js.js` を実行してください。** 右上の ⓘ で表示する文（`js/readme-text.js`）が、README と同じ内容に作り直されます（`index.html` をダブルクリックで開いたときはブラウザが README.md を読み込めないため、同じ文をスクリプトの形でも持っています）。作り直し忘れは `node tests/help.test.js` で分かります。
- ⓘ の先生向けタブに表示しない節は、`js/help.js` の先頭の `TEACHER_HIDDEN` にまとめてあります。節の名前を変えたときは、ここも直してください。
- 「軸が図形の中を通る」かどうかの判定は、`js/geometry.js` の `axisSide` 1か所にまとめてあります。
  `Rev.ALLOW_AXIS_CROSSING` を `false` にすると、第2版までと同じく、軸が図形の中を通るときはエラーになり、円の大きさを決める●も軸の上をすべらず接する位置にだけ吸い付きます。
- 折り返して重ねた形の輪郭は、`js/geometry.js` の `foldProfile` で求めています。
  軸に沿った位置を「頂点・辺が軸を横切る所・折り返した辺どうしが交わる所」で細切れにし、細切れごとに断面を折り返して重ねて、上の端と下の端になる辺を選んでいます。
- 円の大きさを決める●の吸い付き先は、`js/snap.js` の `radiusTargetsOnAxis`（接点と軸上の方眼の交点）にまとめてあります。
- フリーハンドの線を三角形・円などに補正する機能を将来加えるときは、`Freehand.recognizers` に判定を1つ加えます（整えたあと・間引く前に呼ばれ、形を返せばそれを使い、返さなければそのまま）。
