# 回転体をつくろう（中学1年 数学「空間図形」）

平面図形と回転の軸をかくと、図形が軸のまわりを1周して回転体ができるようすを3Dで見られるWeb教材です。
タブレット・Chromebook・パソコンのブラウザで使えます。指・タッチペン・マウスのどれでも操作できます。

---

## 生徒のみなさんへ：使い方

1. **図形を置く**
   「三角形」「四角形」「円」のどれかを押します。
   ●（まる）を指で動かすと、形や大きさを変えられます。図形の内側を動かすと、図形全体が動きます。
   円の大きさを決める●は、中心のまわりのどの向きにも動かせます。
2. **軸を引く**
   「軸を引く」を押してから、方眼の上を2か所タップします。その2つの点を通る赤い点線が「回転の軸」です。
   ◆（ひし形）を動かすと、軸の位置を変えられます。
3. **軸にぴったり合わせる（吸い付き）**
   ●を軸に近づけると、軸に吸い付いて**緑色**になります。緑の●は「軸にぴったり合っている」しるしです。
   - 吸い付いたまま動かすと、●は軸の上をすべります。
   - 軸から大きく離すと外れて、ふつうに動かせます。
   - 図形全体を動かして、頂点を軸に近づけても吸い付きます。2つの頂点を軸に合わせると、辺が軸に重なります。
   - 円の大きさを決める●を軸に近づけると、円が軸にぴったり接します。接したまま中心を動かすと、円は軸に沿ってすべります。
4. **回転させる**
   「回転させる」を押すと、右側で図形が軸のまわりを1周して、回転体ができます。

**右側の立体の見かた**

- 1本指でなぞる → 立体が回る
- 2本指で広げる・せばめる → 大きく・小さく見える（マウスのときはホイール）
- 「半透明」 → 立体がすけて、中の軸ともとの図形が見える
- 「もう一度」 → 回転のようすをもう一度見る
- 「はじめの向き」 → 見る向きをもとにもどす
- 「全部消す」 → 最初からやり直す

**ためしてみよう**

- 長方形の1辺の上に軸を引くと → 円柱
- 直角三角形の、直角をはさむ辺の上に軸を引くと → 円錐
- 円を軸からはなすと → ドーナツの形
- 円を軸にぴったり接するようにすると → まん中の穴が点になったドーナツの形
- 長方形を軸からはなすと → まん中が空洞の円柱

軸が図形の中を通っていると、回転体はつくれません（「軸が図形の中を通っています…」と表示されます）。
軸を図形の外か、辺の上に引き直してください。

## 先生方へ

### 教材の開き方

- **インターネットで公開して使う（おすすめ）**：GitHub Pages で公開すると、生徒は URL を開くだけで使えます（手順は下）。
- **ファイルを直接開く**：このリポジトリをダウンロード（「Code」→「Download ZIP」）して展開し、`index.html` をダブルクリックしても動きます。インストールや変換作業はいりません。

3D表示に使っている three.js は `vendor/three/` に入っていて、そこから読み込みます。
学校のネットワークで外部サイト（CDN）が遮断されていても動きます。

### GitHub Pages での公開手順

1. 教材のファイルが `main` ブランチに入っていることを確認します。
2. GitHub のリポジトリのページで **Settings → Pages** を開きます。
3. 「Build and deployment」の **Source** を「Deploy from a branch」にし、**Branch** を `main`、フォルダを `/ (root)` にして **Save** を押します。
4. 数分後、同じページに公開先の URL（`https://ユーザー名.github.io/revolution/` の形）が表示されます。これを生徒に配ります。

### データの扱い

- 生徒がかいた図形や軸は、その端末のブラウザの中だけで計算・表示します。
- どこにも送信しません。保存もしません（ページを閉じたり再読み込みしたりすると消えます）。
- 外部のサイトやフォントへの接続もありません。

### 授業での使い方の例

- 「長方形のどの辺を軸にすると、どんな円柱ができるか」を予想させてから確かめる。
- 同じ直角三角形でも、軸にする辺を変えると円錐の形が変わることを比べる。
- 軸を図形から少しずつはなしていき、円柱 → 空洞のある円柱、円 → ドーナツ形 と変わるようすを観察する。
- 「半透明」にして、立体の中にもとの平面図形と軸があることを確認する。

### 作図のきまり

- 図形は一度に1つです。別の図形のボタンを押すと置きかわります。
- 頂点・円の中心・軸の点は方眼の交点に、円の半径は 0.5 ます刻みに吸いつきます。このため、辺の上にぴったり軸を引けます。
- 軸を引いたあとは、図形の点が軸にも吸い付きます（画面上でおよそ20ピクセル以内に近づけたとき）。
  - 頂点：軸の上に乗り、軸の上をすべります。軸の上の方眼の交点の近くでは、その交点に乗ります。図形全体を動かしたときも、軸に近づいた頂点が軸に乗ります。
  - 円：大きさを決める●を軸に近づけると、円が軸に接します（半径 ＝ 中心から軸までの距離）。接したまま中心を動かすと、軸に沿ってすべります。
  - 軸にぴったり合っている点は緑色で表示され、案内の欄にも「緑の●は、軸にぴったり合っています」と出ます。
  - 斜めの軸でも同じように吸い付きます。斜めの軸の場合、吸い付いた頂点は方眼の交点からずれることがあります（それで正しい位置です）。
- 四角形は、辺が交差する形やつぶれた形にはなりません（そうなる動かし方は受け付けません）。

### 回転体の正しさについて

図形の輪郭（ふち）を軸のまわりに1周させてできる面で立体をつくっています。
このため、軸が辺に重なる場合（円柱・円錐）も、軸が図形から離れている場合（空洞の円柱・ドーナツ形）も、数学的に正しい形になります。
`tests/geometry.test.js` で、できた立体の体積が教科書の公式（円柱 πr²h、円錐 πr²h/3、ドーナツ形 2π²Rr² など）と合うことを確かめています。
軸に吸い付けてつくった形（軸に接する円、頂点や辺が斜めの軸の上にある三角形など）の体積も確かめています。
吸い付きの動き（吸い付く・すべる・外れる）は `tests/snap.test.js` で確かめています。
Node.js が入っているパソコンでは `node tests/geometry.test.js` と `node tests/snap.test.js` で実行できます（授業で使うだけなら不要です）。

### まだできないこと

- 軸が図形の内部を通る場合の回転体（メッセージを表示して、回転させません）
- 図形を2つ以上置くこと、自由な多角形や曲線をかくこと
- 作った図形の保存・印刷

### 今後の拡張のためのメモ（開発する人向け）

- 「軸が図形の中を通る」かどうかの判定は、`js/geometry.js` の `axisSide` 1か所にまとめてあります。
  軸をまたぐ図形の回転に対応するときは、`Rev.ALLOW_AXIS_CROSSING` を `true` にし、`analyze` の中で軸をまたぐ場合の立体の作り方を加えます。
- 円の大きさを決める●の吸い付きは、`js/snap.js` の `snapRadiusHandle` にあります。
  `ALLOW_AXIS_CROSSING` が `true` になると、●は軸の上をすべって半径が変わり（円が軸と2点で交わる）、接する位置（`radiusTargetsOnAxis` の一覧）に吸い付く動きになります。この動きはテスト（`tests/snap.test.js` の［将来］の項目）で確かめてあります。
